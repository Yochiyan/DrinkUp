# DrinkUp!
DrinkUp!は水分摂取の記録に特化したアプリです。
画面は大きく分けて初期設定、ホーム画面、編集画面の３つに分かれ、複雑な作業を行わずに水分摂取量を把握することができます。
>[!NOTE]
><n>このアプリを利用する際はマイボトルをご用意ください。</n>
## 初期設定画面
アプリを初めて起動した際、ヘルスケアへのアクセスを求められます。お好みに設定してください。なお、アクセス権を与えなかった場合でもアプリ内でのみ記録することができます。<br>
ご自身のボトルの容量を入力してください。
## ホーム画面
初期設定が済んだ後の画面となります。上から順に、登録したボトルの情報。編集とヘルスケアへの同期ボタン。今日の合計。累計。累計節約額。飲み切った！ボタン。履歴。の画面構成となっています。
### 登録したボトル
登録されているボトルの容量が表示されています。この情報はいつでも編集可能です。
### 編集ボタン
登録しているボトルの値を編集するためのボタンです。
### 同期ボタン
ヘルスケアにデータを一括で書き込むボタンです。**通常は押す必要はありません。**<br>
開発時にヘルスケアに同期する機能を追加したときに、今までのデータをヘルスケアにインポートする必要があったため実装した機能となります。<br>
後からヘルスケアへの権限を与えたときにアプリのデータを書き込む際にご利用ください。
>ボタンを複数回押した時などはデータが重複して記録される可能性があります。このアプリからデータを消去する機能はありません。
### 今日の合計
１日の水分補給量を表します。日を跨ぐとリセットされます。
### 累計
このアプリで記録した完全な水分補給量を表示します。
### 累計節約額
大学の自動販売機の水を買う時と比較してどのくらい節約できているか完全な金額を表示します。コカ・コーラ社のいろはす　540ml 120円を参考に設定しています。
>[!NOTE]
>編集機能は実装していません。IDE側で値を編集する必要があります。
### 飲み切った！ボタン
その名の通り、ボトル内の水を飲み切った時にこちらのボタンを押してください。即座に補給したことを記録されて、権限がある場合はヘルスケアにも記録されます。
### 履歴
履歴を表示します。その時に飲んだ水の量。日付と時間も記録されます。
## 編集画面
登録したボトルの容量を変更することができます。編集ボタンを押した時にこの画面が表示されます。<br>
値を入力したら、保存ボタンを押して元の画面に戻ってください。
